# SCHUNK Mechatronic Gripper Assets

Simulation and visualization assets for SCHUNK mechatronic grippers. The repository contains Unified Robot Description Format (URDF) models, Universal Scene Description (USD) assets, and the mesh files required by each model.

## Available Assets

| Gripper family | Model | URDF | USD | Meshes |
| --- | --- | --- | --- | --- |
| EGK | EGK 25 | - | [schunk_egk_25.usd](EGK/EGK%2025/schunk_egk_25.usd) | Included in USD asset |
| EGK | EGK 40 AIS | [schunk_egk40_ais.urdf](EGK/EGK%2040%20AIS/schunk_egk40_ais.urdf) | [SCHUNK_EGK_40_AIS.usd](EGK/EGK%2040%20AIS/SCHUNK_EGK_40_AIS.usd) | STL |
| EGU | EGU 50 | - | [schunk_egu_50.usd](EGU/EGU%2050/schunk_egu_50.usd) | Included in USD asset |
| EZU | EZU 35 | - | [schunk_ezu_35.usd](EZU/EZU%2035/schunk_ezu_35.usd) | Included in USD asset |
